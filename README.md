# Сайрам доставка

Фастфуд ва дўконлар учун буюртма платформаси. Битта сервер, тўртта саҳифа:

| Саҳифа | Ким учун | Ҳаво |
|---|---|---|
| Мижоз сайти | Мижозлар | `/` |
| Админ панел | Фақат сиз | `/admin` |
| Заведение панели | Фастфуд ва дўкон эгалари | `/vendor` |
| Курьер | Курьерлар | `/courier` |

## Ишга тушириш (компьютерингизда)

1. Node.js 20+ ўрнатинг (nodejs.org).
2. Папкада: `npm install`
3. Админ логини ва паролини ўзингиз танланг ва ишга туширинг:

   Windows (PowerShell):
   ```
   $env:ADMIN_PHONE="сизнинг-логин"; $env:ADMIN_PASSWORD="узун-кучли-парол"; npm start
   ```
   Mac/Linux:
   ```
   ADMIN_PHONE=сизнинг-логин ADMIN_PASSWORD=узун-кучли-парол npm start
   ```
4. Браузерда `http://localhost:3000` (мижоз) ва `http://localhost:3000/admin` (админ).

Агар ADMIN_PASSWORD бермасангиз, парол тасодифий яратилади ва консолда **бир марта** кўрсатилади.
Админ фақат битта: ундан бошқа ҳеч ким админ бўла олмайди.

## Ишлатиш тартиби

1. `/admin` га кириб, **Созламалар**да етказиш нархи ва Kaspi телефонни ёзинг.
2. **Заведение қўшинг**: тури, номи, комиссия %, ва эгасига логин (телефон) ва парол беринг.
3. Эгаси `/vendor` га шу логин билан кириб, ўз менюсини ўзи қўшади ва буюртмаларни қабул қилади.
4. **Курьер қўшинг**: у `/courier` дан кириб, бўш буюртмаларни олади.
5. Буюртма йўли: Янги, Қабул қилинди (заведение), Тайёр (заведение), Йўлда (курьер), Етказилди (курьер).

Комиссия: ҳар бир буюртма маҳсулотлари суммасидан заведениега белгиланган фоиз. Етказиш ҳақи курьерга. Админ панелда етказилган буюртмалар бўйича сизнинг комиссиянгиз кўринади.

## Тўлов

- **Нақд:** курьер пулни олади ва "Етказдим" босганда тўланган деб белгиланади.
- **Kaspi ўтказма:** мижозга админ созламаларидаги Kaspi телефон кўрсатилади. Пул тушгач, заведение "Kaspi тўлови тушди" тугмасини босади. Бу қўлда тасдиқлаш, Kaspi API эмас.
- Kaspi Pay API (автоматик тўлов) учун Kaspi билан ИП номига шартнома керак. Шундан кейин `server.js` га тўлов модулини қўшиш мумкин.

## Харита

Мижоз харитада жойини белгилайди (OpenStreetMap, калит керак эмас). Курьер ва заведение Google харита ва 2ГИС ҳаволаларини кўради. Тўлиқ йўл чизиш ва реал вақтда кузатув учун 2ГИС API калити керак бўлади.

## Интернетга чиқариш (муҳим)

- Сервер доим ишлаб туриши керак: VPS (ойига тахминан 5 доллар) ёки Render/Railway каби хизмат. Тўловли аккаунтни катта ёшли одам (апайингиз) очиши керак.
- Маълумот `data.db` файлида. Серверда бу файл **ўчиб кетмайдиган** дискда бўлиши ва мунтазам нусха олиниши шарт.
- HTTPS (ёпиқ қулф) шарт, акс ҳолда логин-парол ҳимояланмайди. Render/Railway буни ўзи беради, VPS да Caddy ёки nginx + Let's Encrypt керак.
- Мижозларнинг телефони ва манзили шахсий маълумот, уни ҳимоя қилиш сизнинг масъулиятингиз.

## Нима ҳали йўқ

Мижоз ҳисоби/тарихи (ҳозир буюртмалар шу браузерда сақланади), push-хабарнома (панелларда 8-15 сонияда янгиланади), курьерни реал вақтда харитада кузатиш, автоматик Kaspi тўлов, такси.
